Recommendations

  • Pre-commit hooks: run Gitleaks or TruffleHog on every commit; block pushes that match AKIA patterns.
  • .env files: never commit .env / .env.local; use .env.example with placeholders only.
  • CI/CD: inject secrets via GitHub Actions secrets / OIDC — not hardcoded in workflow YAML.
  • GitHub Advanced Security: enable secret scanning + push protection on org repos.
  • Test fixtures: redact or mock credentials in fixtures/, tests/, and sample data — many hits come from non-production paths.
  • Terraform / IaC: use remote state + variable files excluded from git; scan .tf and .tfvars in PR checks.

Aggregated statistics only. No access keys, secret keys, or source file URLs are published in this report.
